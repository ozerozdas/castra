# Upgrading to 0.4.3

<!-- upgrade-from: v0.4.2 -->

Security patch release for dependencies (`hono` CVE-2026-126355 to -126359, `@hono/node-server`
CVE-2026-126210 and -126343): no database migration, binding or API change. From 0.4.1, first apply the
[0.4.2 upgrade](0.4.2.md).

Bump the `@castra-kit/*` packages to `0.4.3` and the dev tooling below, then run `pnpm install`. Projects scaffolded
with `create` before 0.4.3 likely pin `better-auth` 1.7.7: raise it to `1.7.22` so it matches `@castra-kit/auth`
and pnpm stops installing two copies. Run `pnpm update @hono/node-server` too (or a full `pnpm update`) so the
transitive copy resolves to 2.1.6 or later.
