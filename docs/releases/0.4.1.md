# v0.4.1 — Dependency patch release

**Date:** 2026-10-26

Patch release that rolls up the pending Dependabot updates. No feature, API, schema or MCP surface change.

## Changed

- `better-auth` 1.7.9 → 1.7.12 in `@castra-kit/auth` (Dependabot #33).
- `kysely` 0.29.6 → 0.29.7 across the packages and the blog example (Dependabot #32).
- Dev tooling (Dependabot #29, #31): `wrangler` 4.151.3, `@cloudflare/workers-types` 5.20261022.1,
  `@cloudflare/vitest-plugin` 1.4.6, `eslint` 10.13.0, `typescript-eslint` 8.72.0, `@readme/openapi-parser` 10.0.0.

## Not taken

- `@types/node` 22 → 25 (Dependabot #30). The packages support Node >=20 and CI runs on 22; Node 25 types would let
  code typecheck against APIs the supported runtimes lack, and they conflict with `@cloudflare/workers-types` on
  `URL` in `@castra-kit/cli`. `.github/dependabot.yml` now ignores `@types/node` major updates.

## Migration

- No database migration is required.

## Upgrade

1. Bump `@castra-kit/*` packages to `0.4.1`.
2. Run `pnpm install`.

## Publication

Release gate passed locally: lint/build/typecheck, 1295 full-suite tests (7 opt-in skipped), 529 policy tests,
2 upgrade tests.
