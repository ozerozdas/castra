# @castra-kit/auth

Better Auth wiring, roles and request identity for Castra.

Part of [Castra](https://github.com/ozerozdas/castra). Start a new app with:

```
npm create @castra-kit@latest my-app
```

Docs: [getting started](https://github.com/ozerozdas/castra/blob/master/docs/getting-started.md), the [security model](https://github.com/ozerozdas/castra/blob/master/docs/SECURITY.md) and [D1 limits](https://github.com/ozerozdas/castra/blob/master/docs/limits.md).
Error types are documented at https://castra.mehmetozer.dev/problems/.
