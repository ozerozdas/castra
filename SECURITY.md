# Security policy

## Supported versions

Only the latest release of the `@castra-kit/*` packages receives security fixes.

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through
[GitHub security advisories](https://github.com/ozerozdas/castra/security/advisories/new) (Security tab →
"Report a vulnerability").

Include the affected version or commit, a reproduction (config, request, expected and actual result) and the impact.
Policy bypasses, data leaks across users, and SQL injection are the most important classes for this project.

This is an early-stage project maintained without a service level. Reports are acknowledged and handled as time
allows; fixed issues are published as advisories with credit, unless you ask otherwise.

## Threat model

What Castra protects, what it relies on, and its known issues are in [docs/SECURITY.md](docs/SECURITY.md).
